Q: big o, time complexity, complexity, space complexity, performance algorithm
T: CS - Big-O
A:
O(1) constant - dict/hash lookup, array index
O(log n) - binary search
O(n) - one loop over the data
O(n log n) - good sorting (merge sort, sorted())
O(n^2) - loop inside a loop
O(2^n) - naive recursion like fibonacci
Tip: a hash map (dict / Map / HashMap) often turns O(n^2) into O(n).

Q: binary search, sorting algorithm, quicksort, merge sort, bubble sort, sort algorithm
T: CS - binary search and sorting
A:
```python
def binary_search(items, target):     # items must be sorted
    lo, hi = 0, len(items) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if items[mid] == target: return mid
        if items[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```
Sorting: use the built-in sort (n log n). Merge sort = split, sort halves, merge.
Quicksort = pick pivot, smaller left, bigger right. Bubble sort = slow O(n^2), only for learning.

T: CS - recursion
A:
```python
def factorial(n):
    if n <= 1:          # base case - always needed!
        return 1
    return n * factorial(n - 1)

from functools import lru_cache
@lru_cache(None)        # memoization makes this fast
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Q: debug, debugging, bug, how to debug, fix bug, not working, broken
T: Tips - how to debug
A:
1. Reproduce it reliably - what exact steps break it?
2. Read the WHOLE error message and the line number.
3. Print/log values around the problem (or use a breakpoint).
4. Shrink the problem: remove code until it works, then add back.
5. Check recent changes:  git diff
6. Explain it out loud to me (rubber-duck... rubber-dog debugging!)
7. Search the exact error text:  type  search <error>

for i in range(1, 16):
    print("FizzBuzz" if i % 15 == 0 else "Fizz" if i % 3 == 0 else "Buzz" if i % 5 == 0 else i)

def two_sum(nums, target):            # O(n) with a dict
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen: return [seen[target - n], i]
        seen[n] = i

is_palindrome = lambda s: s == s[::-1]
is_anagram = lambda a, b: sorted(a) == sorted(b)
